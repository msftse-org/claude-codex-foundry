# Claude & Codex Admin

The console manages a customer's existing Azure gateway. It uses the supplied Watermark direction: warm paper, blue-green ink, a serif voice, legible operational type, thin rules, and restrained motion. A quiet organization seal belongs only in the overview and organization mark. Tables and settings remain flat; floating dialogs alone have shadows.

The primary tasks are understanding usage, governing access, reviewing token limits, and onboarding developers. Show consequences before publishing gateway policy. Drafts are distinct from deployed configuration. Every mutation records its actor and changes. Azure errors must never look like empty or successful results.

Components: responsive sidebar, command search, page header, written overview, metric figure, usage chart with table alternative, searchable table, status label, accessible dialog, impact preview, staged deployment bar, empty/error states, theme selector, audit detail, and download action.

Light/dark tokens live in web/src/tokens.css. System preference is the default. Spectral carries headings; Atkinson Hyperlegible Next carries controls and data. Fonts are bundled, with no third-party font requests. All pages must remain usable by keyboard and on narrow screens.
